# 光谱调节需求PRD

终测和光谱调节其实是同一份代码

光谱调节也是Interleavr的一道工序，现在光谱调节要做自动化 从我们这个软件对接到自动化运动控制，达成替代人工的目的

根据业务方沟通，光谱调节在过程中会产生很多数据，对应就是波形数据，这些数据我要发给自动化那边，给他们使用。

我这里唯一的需求就是能提供接口给到自动化，给他需要的光谱数据就行  过程数据和结果数据都能够提供

## 方案
方案1 做服务端socket 

方案2 所有数据都放到一个共享目录上去

## 选定与契约

采用 **方案2（共享目录）+ 现有 Socket 通知路径**。  
消费端接口说明见：[光谱调节_自动化数据接口.md](光谱调节_自动化数据接口.md)（apiVersion 1.0）。
