# 光谱调节 — 自动化数据接口（消费端契约）

| 项 | 值 |
|----|-----|
| **apiVersion** | `1.0` |
| **提供端** | OCITS / `UIOperateInterleaver`（光谱调节工序） |
| **消费端** | 自动化运动控制 |
| **传输** | 共享目录文件（主）+ TCP 文本消息（事件通知） |
| **非目标** | 本接口不是 HTTP；不在 Socket 中传输完整谱线数组 |

关联需求：[光谱调节PRD.md](光谱调节PRD.md)

---

## 1. 概述

调节扫描产生的**过程光谱**与**结果光谱/标量**由提供端写入共享目录；落盘成功后经现有 ClientSocket 向自动化发送 `DATA;READY` 通知。消费端收到通知后按路径读取文件做闭环调光。

```text
自动化 --TCP命令--> OCITS --扫描--> 写共享目录
自动化 <--TCP事件-- OCITS（DATA;READY / TEST;PASS / TEST;FAIL）
自动化 --读文件--> 共享目录（meta / spectrum / result）
```

---

## 2. 连接与鉴权

| 项 | 说明 |
|----|------|
| 角色 | OCITS 为 **TCP Client**，连接自动化侧 **TCP Server** |
| 地址 | 来自工位设备配置中的 Automation（IP/Port） |
| 鉴权 | 无；依赖产线内网与工位配置 |
| 启用条件 | `AutomationType == 1` 时建立连接并发事件 |

消息编码：ASCII/UTF-8 文本行，字段以 `;` 分隔，行尾 `\r\n`。

---

## 3. 命令接口（自动化 → OCITS）

均为**异步**：OCITS 收到后启动本地流程，结果以事件回传（非同步 RPC）。

| 命令 | 示例 | 行为 |
|------|------|------|
| 打开模板 | `SNNO;{SN}\r\n` | 使用 SN 打开无纸化模板 |
| 调节扫描（无 PDL） | `TEST;NOPDL\r\n` | 触发「调节」扫描，产生 **process** 数据 |
| 测试扫描（PDL） | `TEST;PDL\r\n` | 触发「测试」扫描，产生 **result** 数据 |
| 照光标记 | `TEST;UV;{SN};{0\|1}\r\n` | 照光分支；应答 `TEST;UV;PASS\r\n` |

说明：路径中勿使用 `;`（路径放在 `DATA;READY` 最后一字段）。

---

## 4. 事件 / 应答（OCITS → 自动化）

### 4.1 既有结果标量（兼容）

| 事件 | 示例 / 说明 |
|------|-------------|
| 成功标量 | `TEST;PASS;{shift…};{maxIL};{FSR};…\r\n`（字段顺序为历史约定，详见实现 `UpdateSpecialParam`） |
| 扫描失败 | `TEST;FAIL\r\n` |
| 照光 ACK | `TEST;UV;PASS\r\n` |
| 开模板 | `SNNO;PASS;…` / `SNNO;FAIL;…`（既有逻辑） |

### 4.2 光谱数据就绪（新增）

落盘成功后发送（**不**在扫失败时发送）：

```text
DATA;READY;{apiVersion};{SN};{dataKind};{scanType};{datasetDir}\r\n
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `DATA` | const | 固定 |
| `READY` | const | 固定 |
| apiVersion | string | 如 `1.0`，与本文档一致 |
| SN | string | 产品序列号 |
| dataKind | string | `process`（调节/NoPDL）或 `result`（测试/PDL） |
| scanType | string | `NOPDL` 或 `PDL` |
| datasetDir | string | 本批数据集**绝对目录**（其下含 meta/spectrum/result） |

示例：

```text
DATA;READY;1.0;K6084998;process;NOPDL;D:\ITL_SpectrumShare\Interleaver-ITL-调节\K6084998\20260806103015_001\r\n
```

时序（一次调节扫）：

1. 自动化发 `TEST;NOPDL`
2. OCITS 扫描并计算
3. 写共享目录文件
4. 发 `DATA;READY;…`
5. （随后仍可能发）`TEST;PASS;…` 标量串

## 5. 文件资源（共享目录）

### 5.1 根路径配置

自动化与调节软件**同机部署**时，推荐固定本机目录（不用 UNC）：

| 项 | 值 |
|----|-----|
| **推荐根目录** | `D:\ITL_SpectrumShare` |
| 配置文件 | 运行目录 `set\SpectrumShareRoot.txt`，第一行非空路径（`#` 开头行为注释） |
| 无 D: 盘 | 改为 `C:\ITL_SpectrumShare`（只改配置，不必改代码） |
| 缺省（无配置文件） | `{exe运行目录}\SpectrumShare` |

示例文件见 [set/SpectrumShareRoot.example.txt](set/SpectrumShareRoot.example.txt)。

`DATA;READY` 中的 `datasetDir` 为**绝对路径**，例如：

`D:\ITL_SpectrumShare\Interleaver-ITL-调节\K6084998\20260806103015_001`

### 5.2 路径模板

```text
{ShareRoot}\{TestProcess}\{SN}\{yyyyMMddHHmmss}_{seq3}\
  meta.json
  spectrum.csv
  result.json
```

| 段 | 说明 |
|----|------|
| TestProcess | 工位工序名（如调节工序名） |
| SN | 产品号 |
| 时间戳_序号 | 同 SN 下多次扫描区分；`seq3` 为当日递增三位序号 |

目录生命周期：由消费端或现场策略清理；提供端只追加写入，不自动删除历史批次。

### 5.3 `meta.json`

| 字段 | 类型 | 说明 |
|------|------|------|
| apiVersion | string | `1.0` |
| sn | string | SN |
| testProcess | string | 工序 |
| port | int | 起始扫描端口（如 1 表示 PORT1，同时含成对 PORT2） |
| scanType | string | `NOPDL` / `PDL` |
| dataKind | string | `process` / `result` |
| createdUtc | string | ISO-8601 UTC |
| spectrumFile | string | `spectrum.csv` |
| resultFile | string | `result.json` |
| pointCount | int | 光谱点数 |
| pmCount | int | 功率计/通道列数 |

示例：

```json
{
  "apiVersion": "1.0",
  "sn": "K6084998",
  "testProcess": "Interleaver-ITL-调节",
  "port": 1,
  "scanType": "NOPDL",
  "dataKind": "process",
  "createdUtc": "2026-08-06T02:30:15Z",
  "spectrumFile": "spectrum.csv",
  "resultFile": "result.json",
  "pointCount": 10001,
  "pmCount": 2
}
```

### 5.4 `spectrum.csv`

与历史 `WriteRawdataToNet` 一致：

- 算法为 Ave 时表头：`GHZ,AVE-1,AVE-2,…`
- 否则表头：`GHZ,AVE-1,MAX-1,MIN-1,AVE-2,MAX-2,MIN-2,…`
- 频率单位：GHz；功率：dB（与软件曲线一致）
- 行数 = 点数；数值小数格式与现网 rawdata 一致

### 5.5 `result.json`

固化 `TEST;PASS` 同源标量（命名字段，便于消费端解析）：

| 字段 | 类型 | 说明 |
|------|------|------|
| apiVersion | string | `1.0` |
| sn | string | SN |
| dataKind | string | `process` / `result` |
| scanType | string | `NOPDL` / `PDL` |
| shifts | number[] | 中低高频等 shift（顺序与界面 specialShifts 一致） |
| maxIL | number[] | 各端口 MaxIL |
| fsr | number[] | 各端口 FSR（无则空数组） |
| minIso | object | 如 `{"PORT1":…,"PORT2":…}`（缺省可不出现键） |

## 6. 过程 vs 结果

| dataKind | 触发 | 用途 |
|----------|------|------|
| `process` | `TEST;NOPDL` / UI「调节」扫成功 | 调光过程中的光谱，可多次 |
| `result` | `TEST;PDL` / UI「测试」扫成功 | 判定用结果光谱 + 标量 |

同 SN 多次 `process` 靠目录名时间戳/序号区分；消费端应按 `DATA;READY` 的 `datasetDir` 消费，勿假设固定文件名覆盖。

---

## 7. 错误与边界

| 场景 | 行为 |
|------|------|
| 扫描失败 | 发 `TEST;FAIL`；**不**发 `DATA;READY`；不写本批共享目录 |
| 共享盘不可写 | 写 `Log`；界面/流程**不阻断**；不发 `DATA;READY` |
| Socket 断开 | 落盘仍尝试；`DATA;READY` 发送失败仅记日志 |
| 用户停止扫描 | 不发布本批数据 |
| 路径过长/非法字符 | 记日志失败；不阻断扫描 |

消费端建议：收到 `DATA;READY` 后再读文件；读前确认 `meta.json` 与 `spectrum.csv` 均存在；超时未收到 READY 则按扫失败处理。

---

## 8. 版本规则

- `apiVersion` 出现在 `meta.json`、`result.json`、`DATA;READY`。
- **兼容变更**（仅增可选字段）：次版本可不变或 `1.1`。
- **不兼容变更**（删字段、改语义、改路径模板）：升主版本，并同步本文档。
